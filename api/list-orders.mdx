---
title: "List Orders"
description: "Get open orders or order history for an exchange"
---

`GET /api/v1/orders`

Returns orders for the authenticated user on the specified exchange.

`status=open` preserves the current open-order behavior.
`status=closed|all` enables order history on supported exchanges.

## Error Semantics

- `400` means the query shape is invalid, such as `start_ts > end_ts` or missing `market_id` for Limitless history.
- `403` means credentials/authorization are missing or invalid for private exchange access.
- `501` means the exchange does not support the requested history mode.
- `503` means the upstream exchange is temporarily unavailable (retry with backoff).

## Parameters

<ParamField query="exchange" type="string" required>
  Exchange identifier: `polymarket`, `kalshi`, `limitless`, `opinion`, or `predictfun`.
</ParamField>

<ParamField query="market_id" type="string">
  Filter orders by a specific market ID.
</ParamField>

<ParamField query="status" type="string" default="open">
  `open`, `closed`, or `all`.
</ParamField>

<ParamField query="start_ts" type="number">
  Filter orders created at or after this Unix timestamp in seconds.
</ParamField>

<ParamField query="end_ts" type="number">
  Filter orders created at or before this Unix timestamp in seconds.
</ParamField>

<ParamField query="limit" type="number">
  Max orders to return. For `status=closed|all`, defaults to `100` and clamps to `1..=500`.
</ParamField>

## Support Matrix

- `kalshi`: `open`, `closed`, `all`
- `limitless`: `open`, `closed`, `all` (`market_id` required for `closed|all`)
- `polymarket`, `opinion`, `predictfun`: `open` only

## Response

<ResponseField name="(root)" type="Order[]">
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      Order identifier.
    </ResponseField>
    <ResponseField name="market_id" type="string">
      Market the order is on.
    </ResponseField>
    <ResponseField name="outcome" type="string">
      The outcome being traded.
    </ResponseField>
    <ResponseField name="side" type="string">
      `"buy"` or `"sell"`.
    </ResponseField>
    <ResponseField name="price" type="number">
      Order price.
    </ResponseField>
    <ResponseField name="size" type="number">
      Total order size.
    </ResponseField>
    <ResponseField name="filled" type="number">
      Amount filled so far.
    </ResponseField>
    <ResponseField name="status" type="string">
      One of: `pending`, `open`, `filled`, `partially_filled`, `cancelled`, `rejected`.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 creation timestamp.
    </ResponseField>
    <ResponseField name="updated_at" type="string | null">
      ISO 8601 last update timestamp.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash
# All open orders
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/orders?exchange=polymarket"

# Historical orders on a supported exchange
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/orders?exchange=kalshi&status=closed&limit=50"

# Filtered by market
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/orders?exchange=polymarket&market_id=0x1234abcd"
```
</RequestExample>
