`GET /api/v1/markets`

Returns markets from the gold layer with filtering and pagination. Use this endpoint to search across exchanges, fetch exact markets, or pull every market in one event. Start here when you do not yet know the IDs you need.

## Find the IDs You Need

Use a discovery query first:

```bash
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/markets?exchanges=kalshi&search=bitcoin&limit=1"
```

The response gives you:

- `parsec_id` — Parsec's standard market ID
- `exchange` — source exchange
- `exchange_market_id` — native market ID on that exchange
- `parsec_group_id` / `exchange_group_id` — event identifiers

You can then reuse either `parsec_id` or `exchange + exchange_market_id` on
[`/orderbook`](/api/get-orderbook), [`/price`](/api/get-price),
[`/trades`](/api/get-trades), and [`/execution-price`](/api/get-execution-price).

## Scopes

`/markets` supports four scopes:

| Scope | Use it for | Required selector |
|------|------------|-------------------|
| `list` | discovery, search, filters, pagination | `exchanges` optional |
| `market` | one exact market lookup | `parsec_id` or `exchange + exchange_market_id` |
| `market_batch` | many exact lookups in one request | `parsec_ids` or `external_market_keys` |
| `event` | all markets for one event | `event_id` or `exchange + exchange_group_id` |

If you omit `scope` and pass `parsec_ids`, the server automatically treats the
request as `scope=market_batch`.

## Most Common Request Shapes

| Task | Scope | What to send |
|------|-------|--------------|
| Search and filter markets | `list` | `search`, `exchanges`, `status`, `limit` |
| Fetch one exact market | `market` | `parsec_id` or `exchange + exchange_market_id` |
| Fetch many exact markets | `market_batch` | `parsec_ids` or `external_market_keys` |
| Fetch all markets in one event | `event` | `event_id` or `exchange + exchange_group_id` |

## Query Reference

### Discovery: `scope=list` (default)

### Common

<ParamField query="scope" type="string" default="list">
  Query scope: `list`, `market`, `market_batch`, or `event`.
</ParamField>

<ParamField query="include_matches" type="boolean" default="false">
  When true, each market includes a `matched_markets` array with cross-exchange same-market relations.
</ParamField>

<ParamField query="include_related" type="boolean" default="false">
  When true, each market includes a `related_markets` array with co-dependent market relations.
</ParamField>

### scope=list

<ParamField query="exchanges" type="string">
  Comma-separated exchange IDs: `polymarket`, `kalshi`, `limitless`, `opinion`, `predictfun`. Omit to search across all exchanges.
</ParamField>

<ParamField query="status" type="string" default="active">
  Filter by market status: `active`, `closed`, `resolved`, or `archived`. `scope=list` defaults to `active` when omitted.
</ParamField>

<ParamField query="search" type="string">
  Case-insensitive keyword search across question and description fields.
</ParamField>

<ParamField query="min_volume" type="number">
  Minimum volume filter (USDC).
</ParamField>

<ParamField query="min_liquidity" type="number">
  Minimum liquidity filter (USDC).
</ParamField>

<ParamField query="limit" type="number" default="100">
  Results per page (max 100).
</ParamField>

<ParamField query="cursor" type="string">
  Cursor from the previous response.
</ParamField>

### scope=market

<ParamField query="parsec_id" type="string">
  Single canonical parsec ID (format: `{exchange}:{native_id}`). Mutually exclusive with `exchange` + `exchange_market_id`.
</ParamField>

<ParamField query="exchange" type="string">
  Exchange identifier for external-ID lookup. Must be paired with `exchange_market_id`.
</ParamField>

<ParamField query="exchange_market_id" type="string">
  Exchange-native market ID. Must be paired with `exchange`.
</ParamField>

### scope=market_batch

<ParamField query="parsec_ids" type="string">
  Comma-separated parsec IDs (format: `{exchange}:{native_id}`). Max 100. Mutually exclusive with `external_market_keys`. If `scope` is omitted, the server auto-infers `market_batch`.
</ParamField>

<ParamField query="external_market_keys" type="string">
  Comma-separated external keys (format: `{exchange}:{exchange_market_id}`). Max 100. Mutually exclusive with `parsec_ids`.
</ParamField>

### scope=event

<ParamField query="event_id" type="string">
  Canonical Parsec event ID (exact match). Mutually exclusive with `exchange` + `exchange_group_id`.
</ParamField>

<ParamField query="exchange" type="string">
  Exchange identifier. Must be paired with `exchange_group_id`.
</ParamField>

<ParamField query="exchange_group_id" type="string">
  Exchange-native event/group ID. Must be paired with `exchange`.
</ParamField>

## Cross-Exchange Relation Expansions

Use relation expansions when you want cross-exchange links returned alongside
each market row:

- `include_matches=true` returns `matched_markets`, which represent published `same_market` links
- `include_related=true` returns `related_markets`, which represent published `co_dependent` links
- you can request both in the same call

<RequestExample>
```bash Fetch same_market links
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/markets?scope=market&parsec_id=kalshi:KXBTC-26MAR10&include_matches=true"
```
```bash Fetch co_dependent links
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/markets?scope=market&parsec_id=kalshi:KXBTC-26MAR10&include_related=true"
```
```bash Fetch both relation types
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/markets?scope=market&parsec_id=kalshi:KXBTC-26MAR10&include_matches=true&include_related=true"
```
</RequestExample>

<Warning>
Relation links are precomputed match links. They are decision support, not
ground truth. Before trading, verify the market question, resolution terms,
timing window, and settlement source directly on the source exchange. Links can
still be wrong or incomplete.
</Warning>

## Relation Link Shape

When relation expansions are enabled, each link includes:

<ResponseField name="RelatedMarketLink" type="object">
  <Expandable title="properties">
    <ResponseField name="parsec_id" type="string">
      Counterpart market identifier.
    </ResponseField>
    <ResponseField name="exchange" type="string">
      Counterpart exchange.
    </ResponseField>
    <ResponseField name="confidence" type="number">
      Matching confidence score.
    </ResponseField>
    <ResponseField name="confidence_tier" type="string">
      Pipeline confidence bucket metadata.
    </ResponseField>
    <ResponseField name="source" type="string">
      Matching pipeline source label.
    </ResponseField>
    <ResponseField name="status" type="string | null">
      Counterpart market status when available: `active`, `closed`, or `archived`.
    </ResponseField>
    <ResponseField name="dependency_type" type="string | null">
      Optional dependency classification for `co_dependent` relations.
    </ResponseField>
    <ResponseField name="dependency_direction" type="string | null">
      Optional directionality metadata for `co_dependent` relations.
    </ResponseField>
  </Expandable>
</ResponseField>

## Examples

### 1. Discovery search (`scope=list`)

<RequestExample>
```bash scope=list (default) — Browse active markets
# scope=list (default) — Browse active Polymarket markets
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/markets?exchanges=polymarket,kalshi&search=bitcoin&min_volume=1000&limit=10"
```
</RequestExample>

### 2. Single market lookup (`scope=market`)

<RequestExample>
```bash Using parsec_id
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/markets?scope=market&parsec_id=kalshi:KXBTC-26MAR10&include_matches=true"
```
```bash Using exchange-native selector
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/markets?scope=market&exchange=kalshi&exchange_market_id=KXBTC-26MAR10"
```
</RequestExample>

### 3. Batch lookup (`scope=market_batch`)

<RequestExample>
```bash Using parsec_ids
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/markets?parsec_ids=kalshi:KXBTC-26MAR10,polymarket:572473&include_matches=true"
```
```bash Using external_market_keys
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/markets?scope=market_batch&external_market_keys=kalshi:KXBTC-26MAR10,polymarket:572473"
```
</RequestExample>

### 4. Event-scoped lookup (`scope=event`)

<RequestExample>
```bash Using event_id
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/markets?scope=event&event_id=ev:btc-above-85000-mar-10&include_related=true"
```
```bash Using exchange-native event selector
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/markets?scope=event&exchange=kalshi&exchange_group_id=KXBTC-26MAR10"
```
</RequestExample>
