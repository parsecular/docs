---
title: "List Events"
description: "List normalized events with pagination, optional market expansion, and matched event links."
---

`GET /api/v1/events`

Aggregates normalized markets into event summaries keyed by canonical `event_id`.
Use this endpoint when you want event-level browsing first, then optional market
expansion and published `matched_events` context.

## Error Semantics

- `503` means the market snapshot has not finished loading yet.

## Parameters

<ParamField query="exchanges" type="string">
  Comma-separated exchange IDs to include. Omit to query all exchanges in the current snapshot.
</ParamField>

<ParamField query="search" type="string">
  Keyword search in event titles.
</ParamField>

<ParamField query="status" type="string">
  Event status filter such as `active`, `closed`, or `resolved`.
</ParamField>

<ParamField query="min_volume" type="number">
  Minimum total volume across all markets in the event.
</ParamField>

<ParamField query="include_markets" type="boolean" default="false">
  Include constituent markets directly in the response.
</ParamField>

<ParamField query="limit" type="number" default="50">
  Results per page. Range: 1-100.
</ParamField>

<ParamField query="cursor" type="string">
  Cursor from a previous response.
</ParamField>

## Response

<ResponseField name="(root)" type="object">
  <Expandable title="properties">
    <ResponseField name="events" type="EventSummary[]">
      Event summaries sorted by total volume descending.
      <Expandable title="properties">
        <ResponseField name="event_id" type="string">
          Canonical Parsec event ID.
        </ResponseField>
        <ResponseField name="title" type="string">
          Event title.
        </ResponseField>
        <ResponseField name="market_count" type="number">
          Number of markets in the event.
        </ResponseField>
        <ResponseField name="total_volume" type="number">
          Sum of volume across all markets in the event.
        </ResponseField>
        <ResponseField name="exchanges" type="string[]">
          Exchanges represented in the event.
        </ResponseField>
        <ResponseField name="status" type="string">
          Derived event status.
        </ResponseField>
        <ResponseField name="close_time" type="string">
          Earliest close time across constituent markets.
        </ResponseField>
        <ResponseField name="markets" type="Market[]">
          Constituent markets, only included when `include_markets=true`.
        </ResponseField>
        <ResponseField name="matched_events" type="MatchedEventLink[]">
          Published `same_event` counterparts for this event.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="pagination" type="object">
      Cursor metadata for the result set.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/events?search=super+bowl&include_markets=true&limit=5"
```
</RequestExample>
