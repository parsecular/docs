title: "Get Orderbook"
description: "Fetch the live L2 orderbook or historical orderbook snapshots for a market."
---

`GET /api/v1/orderbook`

Returns the current live orderbook snapshot for a market, or historical
orderbook snapshots when you pass a time range.

Supports two modes:

1. **Live snapshot** (default): Returns the current orderbook from the exchange.
2. **Historical snapshots** (`start_ts`): Returns a paginated series of L2 orderbook snapshots over a time range from S3 Parquet files. Historical data is tier-gated (Free: 5 days, Pro: 30 days, Scale: unlimited).

<Tip>
If you do not know the market identifiers yet, start with [`/markets`](/api/list-markets).
The response gives you `parsec_id`, `exchange`, and `exchange_market_id`, and you can
reuse either selector form here.
</Tip>

## Error Semantics

- `403` means your API key is not authorized for the request.
- `501` means historical snapshots are not configured on this server.
- `503` means the upstream exchange is temporarily unavailable.

## Parameters

<ParamField query="parsec_id" type="string">
  Canonical selector. Provide either `parsec_id` or both `exchange + market_id`.
</ParamField>

<ParamField query="exchange" type="string">
  Exchange selector used with `market_id`.
</ParamField>

<ParamField query="market_id" type="string">
  Exchange-native market ID used with `exchange`.
</ParamField>

<ParamField query="outcome" type="string" default="yes">
  Outcome to fetch, typically `yes` or `no` for binary markets.
</ParamField>

<ParamField query="limit" type="number" default="50">
  Max price levels per side (live mode, range: 1-100) or max snapshots (historical mode, default 500, max 1000).
</ParamField>

<ParamField query="depth" type="number" default="50">
  Alias for `limit`. If both are provided, `limit` takes precedence.
</ParamField>

<ParamField query="start_ts" type="number">
  Unix seconds start timestamp (inclusive). When present, switches to **historical mode** and returns orderbook snapshots instead of a live snapshot. Defaults to 1 day before `end_ts` if only `end_ts` is provided. Historical data is tier-gated (Free: 5 days, Pro: 30 days, Scale: unlimited).
</ParamField>

<ParamField query="end_ts" type="number">
  Unix seconds end timestamp. Defaults to now in historical mode.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from a previous historical response.
</ParamField>

## Response

### Live Mode (default)

<ResponseField name="(root)" type="object">
  <Expandable title="properties">
    <ResponseField name="parsec_id" type="string">
      Canonical market identifier.
    </ResponseField>
    <ResponseField name="exchange" type="string">
      Exchange identifier.
    </ResponseField>
    <ResponseField name="outcome" type="string">
      Selected outcome.
    </ResponseField>
    <ResponseField name="token_id" type="string">
      Exchange-specific asset identifier when available.
    </ResponseField>
    <ResponseField name="market_id" type="string">
      Exchange-native market ID.
    </ResponseField>
    <ResponseField name="bids" type="[price, size][]">
      Present in live mode. Bid levels sorted by price descending.
    </ResponseField>
    <ResponseField name="asks" type="[price, size][]">
      Present in live mode. Ask levels sorted by price ascending.
    </ResponseField>
    <ResponseField name="timestamp" type="string | null">
      Present in live mode. Snapshot timestamp.
    </ResponseField>
    <ResponseField name="tick_size" type="number | null">
      Minimum price increment when available.
    </ResponseField>
    <ResponseField name="min_order_size" type="number | null">
      Minimum order size when available.
    </ResponseField>
  </Expandable>
</ResponseField>

### Historical Mode

Returned when `start_ts` is provided.

<ResponseField name="(root)" type="object">
  <Expandable title="properties">
    <ResponseField name="parsec_id" type="string">
      The requested market identifier.
    </ResponseField>
    <ResponseField name="exchange" type="string">
      Exchange name.
    </ResponseField>
    <ResponseField name="outcome" type="string">
      The outcome for this orderbook.
    </ResponseField>
    <ResponseField name="token_id" type="string">
      Exchange-specific token/asset identifier.
    </ResponseField>
    <ResponseField name="market_id" type="string">
      Exchange-specific market identifier.
    </ResponseField>
    <ResponseField name="snapshots" type="array">
      Array of historical L2 orderbook snapshots, ordered by timestamp ascending.
      <Expandable title="Snapshot properties">
        <ResponseField name="timestamp" type="string">
          Snapshot timestamp (UTC, ISO 8601).
        </ResponseField>
        <ResponseField name="recorded_at" type="string | null">
          When the snapshot was recorded (UTC, ISO 8601).
        </ResponseField>
        <ResponseField name="hash" type="string | null">
          Content hash of the snapshot (for deduplication).
        </ResponseField>
        <ResponseField name="bids" type="array">
          `[price, size]` pairs, sorted by price descending.
        </ResponseField>
        <ResponseField name="asks" type="array">
          `[price, size]` pairs, sorted by price ascending.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="has_more" type="boolean">
      Present in historical mode. Whether more snapshots are available.
    </ResponseField>
    <ResponseField name="next_cursor" type="string | null">
      Present in historical mode. Cursor for the next page.
    </ResponseField>
  </Expandable>
</ResponseField>

## Examples

<RequestExample>
```bash Using parsec_id
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/orderbook?parsec_id=polymarket:572473&outcome=yes&depth=10"
```
```bash Using exchange + market_id
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/orderbook?exchange=polymarket&market_id=572473&outcome=yes&depth=10"
```
</RequestExample>

<ResponseExample>

### Historical snapshots (1 hour window)

```bash
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/orderbook?parsec_id=polymarket:572473&outcome=yes&start_ts=1773100800&end_ts=1773187200&limit=2"
```

```json
{
  "parsec_id": "polymarket:572473",
  "exchange": "polymarket",
  "outcome": "Yes",
  "token_id": "50310842821...",
  "market_id": "572473",
  "snapshots": [
    {
      "timestamp": "2026-03-09T00:00:00Z",
      "bids": [[0.63, 900.0]],
      "asks": [[0.64, 850.0]]
    }
  ],
  "has_more": false,
  "next_cursor": null
}
```


### Paginate through historical snapshots

```bash
# Fetch the next page using the cursor from the previous response
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/orderbook?parsec_id=polymarket:572473&outcome=yes&start_ts=1771581600&end_ts=1771585200&limit=100&cursor=eyJ0cyI6MTc0MDIyMDg0Mn0"
```

<Note>
**Data availability:** Historical orderbook snapshots are served from S3 Parquet files. Snapshot frequency varies by market. For real-time orderbook data, use the live endpoint (omit `start_ts`) or the [WebSocket API](/websocket/overview).
</Note>

For real-time streaming, use the [WebSocket API](/websocket/overview).
