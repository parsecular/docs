---
title: "Get Trades"
description: "Fetch recent or historical public trades for a market outcome."
---

`GET /api/v1/trades`

Returns the public trade tape for a market outcome, using either the normalized or
exchange-native selector.

<Tip>
If you do not know the IDs yet, start with [`/markets`](/api/list-markets). This
endpoint accepts either `parsec_id` or `exchange + market_id`.
</Tip>

## Error Semantics

- `403` means your API key is not authorized for the request.
- `503` means the upstream exchange is temporarily unavailable.

## Parameters

<ParamField query="parsec_id" type="string">
  Canonical selector. Provide either `parsec_id` or both `exchange + market_id`.
</ParamField>

<ParamField query="exchange" type="string">
  Exchange selector used with `market_id`.
</ParamField>

<ParamField query="market_id" type="string">
  Exchange-native market ID used with `exchange`.
</ParamField>

<ParamField query="outcome" type="string" default="yes">
  Outcome selector, typically `yes` or `no` for binary markets.
</ParamField>

<ParamField query="limit" type="number" default="200">
  Max trades to return. Range: 1-500.
</ParamField>

<ParamField query="start_ts" type="number">
  Historical start timestamp in Unix seconds.
</ParamField>

<ParamField query="end_ts" type="number">
  Historical end timestamp in Unix seconds.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from the previous response.
</ParamField>

## Response

<ResponseField name="(root)" type="object">
  <Expandable title="properties">
    <ResponseField name="parsec_id" type="string">
      Canonical market identifier.
    </ResponseField>
    <ResponseField name="exchange" type="string">
      Exchange identifier.
    </ResponseField>
    <ResponseField name="outcome" type="string">
      Selected outcome.
    </ResponseField>
    <ResponseField name="token_id" type="string | null">
      Exchange-specific token/asset identifier for the requested outcome. `null` for exchanges that do not use token IDs (e.g., Kalshi).
    </ResponseField>
    <ResponseField name="market_id" type="string">
      Exchange-native market ID.
    </ResponseField>
    <ResponseField name="trades" type="MarketTrade[]">
      Trade rows ordered newest-first.
    </ResponseField>
    <ResponseField name="has_more" type="boolean">
      Whether more rows are available.
    </ResponseField>
    <ResponseField name="next_cursor" type="string | null">
      Cursor for the next page.
    </ResponseField>
    <ResponseField name="reason" type="string | null">
      Explanatory field for empty results. `null` for normal responses. `"no_data_yet"` when the market exists but has no trade data for the requested range.
    </ResponseField>
  </Expandable>
</ResponseField>

## Examples

<RequestExample>
```bash Using parsec_id
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/trades?parsec_id=kalshi:KXPRESPERSON-28-GNEWS&outcome=yes&limit=5"
```
```bash Using exchange + market_id
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/trades?exchange=kalshi&market_id=KXPRESPERSON-28-GNEWS&outcome=yes&limit=5"
```
</RequestExample>
