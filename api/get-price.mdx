---
title: "Get Price"
description: "Fetch OHLCV candles or a point-in-time price for a market."
---

`GET /api/v1/price`

Returns normalized OHLCV candles for a market. Use it for recent price series,
explicit historical windows, or a point-in-time lookup.

<Tip>
If you do not know the market identifiers yet, start with [`/markets`](/api/list-markets).
This endpoint accepts either `parsec_id` or `exchange + market_id`.
</Tip>

## Error Semantics

- `403` means your API key is not authorized for the request.
- `503` means the upstream exchange is temporarily unavailable.

## Parameters

<ParamField query="parsec_id" type="string">
  Canonical selector. Provide either `parsec_id` or both `exchange + market_id`.
</ParamField>

<ParamField query="exchange" type="string">
  Exchange selector used with `market_id`.
</ParamField>

<ParamField query="market_id" type="string">
  Exchange-native market ID used with `exchange`.
</ParamField>

<ParamField query="outcome" type="string" default="yes">
  Outcome selector. For binary markets this is usually `yes` or `no`.
</ParamField>

<ParamField query="interval" type="string" default="1h">
  Candle interval. Supported values: `1m`, `1h`, `6h`, `1d`, `1w`, `max`.
</ParamField>

<ParamField query="start_ts" type="number">
  Unix seconds start timestamp. Cannot be combined with `at_ts`.
</ParamField>

<ParamField query="end_ts" type="number">
  Unix seconds end timestamp. Cannot be combined with `at_ts`.
</ParamField>

<ParamField query="at_ts" type="number">
  Point-in-time lookup in Unix seconds. Cannot be combined with `start_ts` or `end_ts`.
</ParamField>

## Response

<ResponseField name="(root)" type="object">
  <Expandable title="properties">
    <ResponseField name="parsec_id" type="string">
      Canonical market identifier.
    </ResponseField>
    <ResponseField name="exchange" type="string">
      Exchange identifier.
    </ResponseField>
    <ResponseField name="outcome" type="string">
      Selected outcome.
    </ResponseField>
    <ResponseField name="interval" type="string">
      Candle interval used for the response.
    </ResponseField>
    <ResponseField name="candles" type="Candlestick[]">
      Candles ordered by timestamp.
    </ResponseField>
  </Expandable>
</ResponseField>

## Examples

### Default candle series

<RequestExample>
```bash Using parsec_id
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/price?parsec_id=kalshi:KXPRESNOMD-28-JOSS&interval=1h"
```
```bash Using exchange + market_id
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/price?exchange=kalshi&market_id=KXPRESNOMD-28-JOSS&interval=1h"
```
</RequestExample>

<ResponseExample>
```json
{
  "parsec_id": "kalshi:KXPRESNOMD-28-JOSS",
  "exchange": "kalshi",
  "outcome": "Yes",
  "interval": "1h",
  "candles": [
    {
      "timestamp": "2026-03-10T18:00:00Z",
      "open": 0.51,
      "high": 0.54,
      "low": 0.49,
      "close": 0.52,
      "volume": 1234.0
    }
  ]
}
```
</ResponseExample>

### Explicit historical range

```bash
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/price?parsec_id=kalshi:KXPRESNOMD-28-JOSS&interval=1d&start_ts=1771113600&end_ts=1771718400"
```

### Point-in-time lookup

```bash
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.parsecapi.com/api/v1/price?parsec_id=kalshi:KXPRESNOMD-28-JOSS&interval=1h&at_ts=1771416000"
```
