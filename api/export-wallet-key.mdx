---
title: "Export Wallet Key"
description: "Export the private key for a managed wallet."
---

`POST /api/v1/wallet/export-key`

Exports the private key for one of your active managed wallets.

<Warning>
Treat the returned private key as highly sensitive. Anyone who obtains it can
control that wallet and its funds.
</Warning>

## Parameters

<ParamField body="wallet_type" type="string" required>
  Wallet type to export: `eoa` or `safe`.
</ParamField>

## Response

<ResponseField name="private_key" type="string">
  Hex-encoded private key for the requested wallet.
</ResponseField>

## Notes

- The requested wallet type must exist and be active on your account.
- This endpoint exports the Privy-managed signing key for that wallet record.
- If no active wallet of the requested type exists, the server returns `400`.

<RequestExample>
```bash
curl -X POST "https://api.parsecapi.com/api/v1/wallet/export-key" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "wallet_type": "eoa" }'
```
</RequestExample>

<ResponseExample>
```json
{
  "private_key": "0xabc123..."
}
```
</ResponseExample>
